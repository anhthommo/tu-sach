📋 Hướng dẫn tạo Supabase
Bước 1: Truy cập supabase.com → Đăng ký miễn phí
Bước 2: Tạo New Project → đặt tên, chọn region (Singapore gần nhất)
Bước 3: Vào SQL Editor → chạy đoạn SQL sau:
-- Tạo bảng books
CREATE TABLE books (
  id BIGSERIAL PRIMARY KEY,
  title TEXT NOT NULL,
  author TEXT NOT NULL,
  year INTEGER,
  genre TEXT,
  status TEXT DEFAULT 'unread',
  rating INTEGER DEFAULT 0,
  cover TEXT,
  color TEXT DEFAULT '#1a1008',
  text_color TEXT DEFAULT '#e8d5a0',
  note TEXT,
  quotes JSONB DEFAULT '[]',
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- Cho phép đọc/ghi không cần đăng nhập (chỉ dùng cá nhân)
ALTER TABLE books ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow all" ON books FOR ALL USING (true) WITH CHECK (true);
Bước 4: Vào Project Settings → API → copy:
• Project URL: dán vào ô Supabase URL
• anon key (public): dán vào ô Anon Key
Bước 5: Nhấn "Lưu & Kết nối" — xong! 🎉
* Thông tin được lưu trong localStorage của trình duyệt, chỉ bạn truy cập được.
